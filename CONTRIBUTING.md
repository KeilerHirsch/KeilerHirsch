# Contributing to KeilerHirsch

Thanks for your interest -- issues and pull requests are welcome.

## Ground rules
- Keep commits OPSEC-clean: your commit author email MUST be a GitHub noreply address
  (`<user>@users.noreply.github.com`). Set it locally: `git config user.email ...`.
- Match the existing style; keep each change focused.
- CI must pass before a PR can be merged.

## Rights and provenance

Issues, corrections, source links, and small factual fixes are welcome. Substantial external code, prose, automation, or branding changes require explicit provenance and rights review before merge.

Current project-controlled automation software is offered under PolyForm Noncommercial 1.0.0. Current project-controlled static profile prose is separately licensed under CC BY-NC-SA 4.0. Dynamic third-party/public GitHub data keeps its own source/right status; see `DYNAMIC-DATA.md`.

A substantial contribution may require explicit contributor terms preserving the repository's ability to maintain separate commercial licensing for rights it controls.
