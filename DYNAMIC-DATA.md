# Dynamic Data and External Content Boundaries

The profile README contains blocks refreshed from public GitHub APIs by `scripts/update_profile.py`.

The current dynamic regions are delimited by:
- `RECENT-WORK:START` / `RECENT-WORK:END`
- `OPEN-UPSTREAM:START` / `OPEN-UPSTREAM:END`
- `LATEST-RELEASE:START` / `LATEST-RELEASE:END`

Those blocks can contain public repository names, commit/release facts, dates, branch names, pull-request titles, URLs, and other externally sourced data.

No blanket KeilerHirsch copyright or content-license claim is made over third-party titles, public facts, external repository names, or linked third-party material merely because the updater renders them into this README.

The selection logic, formatting logic, and project-authored surrounding prose remain subject to the applicable project-controlled software/content licenses.

External badges and counters are likewise provided by their respective services and remain subject to those services' rights and terms.
