# AI contributor security protocol

This repository follows the KeilerHirsch AI Security Protocol (v1.0).

Full protocol (secret gist — owner access only): secret gist — ask the owner for the link

This repository is **public**. Everything written here is world-readable by default.
It represents the owner's public identity profile and must stay accurate and non-private.

## Information classification

**PUBLIC** (may appear here):
- Profile facts, links, public research areas, public projects

**INTERNAL** (must NOT appear in a public repo):
- Private contact channels, unreported research, in-progress findings,
  personal data beyond what the owner posted, tooling details

**SECRET** (must never appear anywhere in text):
- Private keys, tokens, credentials, reporters, informants, discovery methods

## Rules for AI assistants

1. Treat every change as public publication.
2. Never write keys, tokens, credentials, or personal data into any file.
3. Do not expand profile claims beyond what is verifiable from the repo.
4. Do not disclose unreported research or in-progress findings.
5. Do not add private contact channels or personal identifiers.
6. Do not fabricate credentials, findings, or affiliations.
7. Commit messages: what changed, minimal reasoning.
8. Keep content minimal and non-revealing.
9. If unsure, ask the owner or keep the minimal-public variant.
10. Never copy private conversation content into a public file.
